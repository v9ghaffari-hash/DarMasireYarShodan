چله‌یار مهدوی – نسخه بومی Kotlin

این پروژه با Kotlin و Android SDK نوشته شده و در رابط کاربری آن از WebView یا HTML استفاده نشده است.

امکانات نسخه پایه:
- صفحه اصلی و نمایش درصد پیشرفت از ۴۰۰ قدم
- ثبت قدم و جدول ۴۰۰ خانه
- ویرایش نام عادت
- تنظیم یادآور روزانه با اعلان اندروید و تکرار روزانه
- پیام روزانه
- ذخیره اطلاعات محلی روی دستگاه

بازکردن در Code On The Go:
1) فایل ZIP را استخراج کنید.
2) پوشه ChillehyarKotlin را به‌عنوان پروژه باز کنید (فایل settings.gradle در ریشه آن است).
3) همگام‌سازی Gradle و سپس اجرای assembleDebug را انجام دهید.

نیازمندی‌ها: Android Gradle Plugin 8.9.1، Kotlin Android Plugin 2.1.20، SDK 36 و JDK سازگار (معمولاً JDK 17).

توجه: این نسخه بومی اولیه است. همه جزئیات و قابلیت‌های نسخه HTML قبلی هنوز به Kotlin منتقل نشده‌اند. ساخت APK در این محیط اجرا و تأیید نشده است. برای اعلان در Android 13 به بالا، مجوز اعلان باید تأیید شود؛ برای زمان‌بندی دقیق نیز ممکن است دسترسی Alarm & reminders لازم باشد.
